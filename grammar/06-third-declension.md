# The Third Declension

The third declension contains every noun that belongs to neither of the
other two. It is the largest declension, the oldest, and the only one whose
nominative singular cannot be trusted.

The endings themselves are few and regular. What varies is the **stem**,
and the whole difficulty of the declension is that the nominative singular
often disguises it.

## Finding the stem: the genitive, not the nominative

Take the genitive singular and remove **-ος**. What is left is the stem,
and every other form is built on it.

| Nominative | Genitive | Stem | |
|:--|:--|:--|:--|
| **ὁ φύλαξ** | **φύλακ-ος** | **φυλακ-** | guard |
| **ἡ ἐλπίς** | **ἐλπίδ-ος** | **ἐλπιδ-** | hope |
| **ὁ ῥήτωρ** | **ῥήτορ-ος** | **ῥητορ-** | orator |
| **τὸ ὄνομα** | **ὀνόματ-ος** | **ὀνοματ-** | name |
| **τὸ γένος** | **γένους** | **γενεσ-** | kind, race |
| **ἡ πόλις** | **πόλεως** | **πολι-**, **πολε-** | city |

This is why a Greek dictionary gives two forms where a Latin dictionary
gives one, and why a vocabulary list that omits the genitive is useless
for third-declension nouns. **φύλαξ** alone tells you nothing;
**φύλαξ, φύλακος** tells you everything.

::: note
**The reason the nominative lies.** The nominative singular of most
masculine and feminine third-declension nouns was formed by adding **-ς**
to the stem, and a consonant meeting that **-ς** changes (§1.5):
**φυλακ-ς → φύλαξ**, **ἐλπιδ-ς → ἐλπίς**. Other stems formed the
nominative by lengthening the last vowel and dropping the **-ς** instead:
**ῥητορ- → ῥήτωρ**.

The disguise is therefore systematic, not random, and a reader who knows
§1.5 can usually run it backwards.
:::

## The endings

One set, used by every consonant stem.

| | **Singular** | **Plural** |
|:--|:--|:--|
| nominative | **-ς** or none | **-ες** |
| genitive | **-ος** | **-ων** |
| dative | **-ι** | **-σι(ν)** |
| accusative | **-α** | **-ας** |
| vocative | stem, or = nom. | **-ες** |

Neuters differ only where the neuter rule (§5.2) requires: nominative,
accusative and vocative have no ending at all in the singular and **-α** in
the plural.

| | **Singular** | **Plural** |
|:--|:--|:--|
| nom. / acc. / voc. | bare stem | **-α** |
| genitive | **-ος** | **-ων** |
| dative | **-ι** | **-σι(ν)** |

Two observations worth making once and then relying on:

- The genitive singular **-ος** and the accusative plural **-ας** are the
  two endings that never change. If you can see one of them, you have the
  declension.
- The accusative singular **-α** looks like a first-declension nominative.
  The article settles it: **τὴν ἐλπίδα** is not **ἡ χώρα**.

## Labial, velar and dental stems

These are the **stop stems**, and their only complication is the dative
plural, where the stem consonant meets **-σι** and behaves exactly as it
does before the **-σ-** of the future (§1.5).

| | **ὁ φύλαξ** *guard* (velar) | **ἡ ἐλπίς** *hope* (dental) |
|:--|:--|:--|
| | **Singular** | |
| nom. | **φύλαξ** | **ἐλπίς** |
| gen. | **φύλακος** | **ἐλπίδος** |
| dat. | **φύλακι** | **ἐλπίδι** |
| acc. | **φύλακα** | **ἐλπίδα** |
| voc. | **φύλαξ** | **ἐλπί** |
| | **Plural** | |
| nom. | **φύλακες** | **ἐλπίδες** |
| gen. | **φυλάκων** | **ἐλπίδων** |
| dat. | **φύλαξι(ν)** | **ἐλπίσι(ν)** |
| acc. | **φύλακας** | **ἐλπίδας** |

The three outcomes:

- labial (**π β φ**) + **σι** → **ψι** : **ὁ Ἄραψ**, dat. pl. **Ἄραψι**
- velar (**κ γ χ**) + **σι** → **ξι** : **φύλακ-σι → φύλαξι**
- dental (**τ δ θ**) + **σι** → **σι** : **ἐλπιδ-σι → ἐλπίσι**

Like **φύλαξ**: **ἡ σάλπιγξ** *trumpet* · **ὁ αἴξ** *goat* ·
**ἡ φλόξ** *flame*. Like **ἐλπίς**: **ἡ πατρίς** *fatherland* ·
**ἡ χάρις** *grace* · **ἡ ἀσπίς** *shield* · **ὁ παῖς** *child*
(stem **παιδ-**, dat. pl. **παισί**).

**Neuter dentals** drop the final **τ** in the nominative singular rather
than adding **-ς**, which produces the very large **-ματ-** class treated
at §6.5.

## Liquid and nasal stems

Stems in **λ ρ μ ν** add nothing in the nominative singular; they lengthen
the stem vowel instead, and the dative plural simply loses the **ν** where
one is there.

| | **ὁ ῥήτωρ** *orator* | **ὁ δαίμων** *spirit* | **ὁ ἀγών** *contest* |
|:--|:--|:--|:--|
| | **Singular** | | |
| nom. | **ῥήτωρ** | **δαίμων** | **ἀγών** |
| gen. | **ῥήτορος** | **δαίμονος** | **ἀγῶνος** |
| dat. | **ῥήτορι** | **δαίμονι** | **ἀγῶνι** |
| acc. | **ῥήτορα** | **δαίμονα** | **ἀγῶνα** |
| voc. | **ῥῆτορ** | **δαῖμον** | **ἀγών** |
| | **Plural** | | |
| nom. | **ῥήτορες** | **δαίμονες** | **ἀγῶνες** |
| gen. | **ῥητόρων** | **δαιμόνων** | **ἀγώνων** |
| dat. | **ῥήτορσι(ν)** | **δαίμοσι(ν)** | **ἀγῶσι(ν)** |
| acc. | **ῥήτορας** | **δαίμονας** | **ἀγῶνας** |

Note the vocative singular: the stem bare, with the accent thrown back as
far as it will go (**ὦ ῥῆτορ**, **ὦ δαῖμον**). This is the one place in the
noun where the accent behaves like a verb's.

Like these: **ὁ ἡγεμών** *leader* · **ὁ λιμήν** *harbour* ·
**ὁ χειμών** *storm* · **ὁ Ἕλλην** *Greek* · **ἡ χείρ** *hand*
(gen. **χειρός**, dat. pl. **χερσί**) · **τὸ ἅλς** / **ὁ ἅλς** *salt, sea*.

## Neuter stems in -ματ-

The commonest neuter type in the language, and the easiest, because the
nominative is simply the stem with its final **τ** gone.

| | **τὸ ὄνομα** *name* | |
|:--|:--|:--|
| | **Singular** | **Plural** |
| nom. | **ὄνομα** | **ὀνόματα** |
| gen. | **ὀνόματος** | **ὀνομάτων** |
| dat. | **ὀνόματι** | **ὀνόμασι(ν)** |
| acc. | **ὄνομα** | **ὀνόματα** |

Like **ὄνομα**: **τὸ σῶμα** *body* · **τὸ πρᾶγμα** *thing, affair* ·
**τὸ γράμμα** *letter* · **τὸ αἷμα** *blood* · **τὸ πνεῦμα** *breath,
spirit* · **τὸ ῥῆμα** *word, saying* · **τὸ στόμα** *mouth*.

A **-μα** noun is neuter without exception, and the whole class is formed
from verbs: it names the *result* of an action. **ποιέω** *I make* gives
**τὸ ποίημα** *a thing made*; **γράφω** gives **τὸ γράμμα**. Recognising
this turns a long vocabulary list into one rule and a verb you already
know.

## Sigma stems

The stem ends in **-εσ-**. Between vowels that sigma dropped out, and the
vowels then contracted, which is why these nouns look irregular and are
not: they are regular endings with a hole in the middle.

| | **τὸ γένος** *kind* | |
|:--|:--|:--|
| | **Singular** | **Plural** |
| nom. | **γένος** | **γένη** (< *γένε-α*) |
| gen. | **γένους** (< *γένε-ος*) | **γενῶν** |
| dat. | **γένει** (< *γένε-ι*) | **γένεσι(ν)** |
| acc. | **γένος** | **γένη** |

Like **γένος**: **τὸ ἔθνος** *nation* · **τὸ ὄρος** *mountain* ·
**τὸ τεῖχος** *wall* · **τὸ ἔτος** *year* · **τὸ ψεῦδος** *falsehood* ·
**τὸ βέλος** *missile*.

Two traps follow from the contraction, and they are worth naming:

- **γένους** is a *genitive singular*, not a nominative; the **-ους** is
  contracted **-εος**.
- **γένη** is a *plural*, not a feminine singular.

The masculine type **ἡ τριήρης** *trireme* (gen. **τριήρους**) declines the
same way with a nominative in **-ης**, and the same stem produces the
third-declension adjectives in **-ης, -ες** (§7.4).

## Stems in ι and υ

Two very common nouns and their class. The genitive singular in **-εως** is
unique to this type and is the surest way to identify it.

| | **ἡ πόλις** *city* | **ὁ πῆχυς** *forearm, cubit* |
|:--|:--|:--|
| | **Singular** | |
| nom. | **πόλις** | **πῆχυς** |
| gen. | **πόλεως** | **πήχεως** |
| dat. | **πόλει** | **πήχει** |
| acc. | **πόλιν** | **πῆχυν** |
| voc. | **πόλι** | **πῆχυ** |
| | **Plural** | |
| nom. | **πόλεις** | **πήχεις** |
| gen. | **πόλεων** | **πήχεων** |
| dat. | **πόλεσι(ν)** | **πήχεσι(ν)** |
| acc. | **πόλεις** | **πήχεις** |

The accusative singular is **-ιν**, not **-ιδα**; the nominative and
accusative plural are identical. The genitive **-εως** keeps its accent on
the antepenult although the ultima is long, in defiance of §2.3 Rule 2.
This is a genuine exception, inherited from an earlier **-ηος**, and it
applies to the whole class.

Like **πόλις**: **ἡ δύναμις** *power* · **ἡ φύσις** *nature* ·
**ἡ πίστις** *faith, trust* · **ἡ τάξις** *order, rank*. All are feminine.

The type in **-ευς** — **ὁ βασιλεύς** *king*, **ὁ ἱερεύς** *priest* — is
close kin:

> **βασιλεύς, βασιλέως, βασιλεῖ, βασιλέα · βασιλῆς** (or **βασιλεῖς**)**,
> βασιλέων, βασιλεῦσι, βασιλέας**

## Irregular nouns worth learning whole

These are frequent enough that learning the paradigm costs less than
working it out each time. All show the same pattern: the stem vowel drops
in the genitive and dative singular and in the dative plural.

| | **ὁ ἀνήρ** *man* | **ὁ πατήρ** *father* | **ἡ μήτηρ** *mother* |
|:--|:--|:--|:--|
| | **Singular** | | |
| nom. | **ἀνήρ** | **πατήρ** | **μήτηρ** |
| gen. | **ἀνδρός** | **πατρός** | **μητρός** |
| dat. | **ἀνδρί** | **πατρί** | **μητρί** |
| acc. | **ἄνδρα** | **πατέρα** | **μητέρα** |
| voc. | **ἄνερ** | **πάτερ** | **μῆτερ** |
| | **Plural** | | |
| nom. | **ἄνδρες** | **πατέρες** | **μητέρες** |
| gen. | **ἀνδρῶν** | **πατέρων** | **μητέρων** |
| dat. | **ἀνδράσι(ν)** | **πατράσι(ν)** | **μητράσι(ν)** |
| acc. | **ἄνδρας** | **πατέρας** | **μητέρας** |

**ἀνήρ** inserts a **δ** between **ν** and **ρ** throughout the oblique
cases, which is a sound change, not a caprice: Greek will not say *ανρ*.

A few more to know on sight, all of them frequent:

| | |
|:--|:--|
| **ἡ γυνή, γυναικός** | woman, wife (voc. **ὦ γύναι**) |
| **ὁ / ἡ παῖς, παιδός** | child (dat. pl. **παισί**) |
| **ἡ ναῦς, νεώς** | ship (acc. **ναῦν**, pl. **νῆες, νεῶν, ναυσί, ναῦς**) |
| **τὸ ὕδωρ, ὕδατος** | water |
| **ὁ Ζεύς, Διός, Διί, Δία** | Zeus (voc. **ὦ Ζεῦ**) |

## The dual

Greek has a third number, for natural pairs: two eyes, two hands, two
brothers, two armies facing each other. It is already receding in fifth-
century Attic, is common in Plato and Aristophanes, and is gone from Koine
entirely (§16.3).

There are only two dual forms in any paradigm — one for the nominative,
accusative and vocative, one for the genitive and dative.

| | nom. / acc. / voc. | gen. / dat. |
|:--|:--|:--|
| article | **τώ** | **τοῖν** |
| first declension | **-ᾱ** : **τὼ χώρᾱ** | **-αιν** : **τοῖν χώραιν** |
| second declension | **-ω** : **τὼ λόγω** | **-οιν** : **τοῖν λόγοιν** |
| third declension | **-ε** : **τὼ φύλακε** | **-οιν** : **τοῖν φυλάκοιν** |
| verb, 2nd person | **-τον** : **λύετον** | |
| verb, 3rd person | **-τον** (past **-την**) | |

A first-year reader needs to recognise a dual and not to form one. The
sign is the article **τώ** or **τοῖν**, and the two commonest words in the
language to meet in the dual are **τὼ ὀφθαλμώ** *the two eyes* and
**τὼ χεῖρε** *the two hands*.
